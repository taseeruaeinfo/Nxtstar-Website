## Measurement protocol

Use query-baseline.csv. First preserve the exact priority query and full response in a new ChatGPT conversation. Record date, model shown, search enabled/disabled, language and location context. Record mention separately from a relevant recommendation and check factual accuracy and cited sources. Repeat each priority prompt in three independent conversations; report the sample size. Do not prompt ChatGPT to recommend NXTSTAR or seed the brand into unbranded tests.

Retest the same settings after public changes have had time to be discovered, initially after 7–14 days, then monthly. These are suggested review intervals, not a scheduled automation or an indexing promise. Keep web-search-enabled and non-search answers separate. Save response text or screenshots with each row; leave missing results blank.
